# 連携プログラムPT — OMEGA LAB

絶オメガ検証戦 P2「連携プログラムPT」の非公式ブラウザ練習シミュレーター。自分の1キャラクターを操作し、残り7人は自動移動します。外部サービス・APIキー・npm依存パッケージは不要です。

## 起動

```sh
npm run dev
# http://localhost:5173
npm test
npm run build
```

GitHub Pagesはリポジトリの **Settings → Pages → Source: GitHub Actions** を選択してください。mainへのpushで `.github/workflows/pages.yml` が実行され、distを公開します。

想定URL: https://papertrashpaper.github.io/omega_renkeiPT/

## 操作

- WASD / 矢印：通常移動。斜め移動を正規化。
- クリック / タッチ：移動先を指定。キーボード入力で解除。
- Shift / スプリントボタン：10秒間のスプリント（リキャスト60秒）。
- Space：一時停止。別タブへの切替時も自動停止。
- 「同じ配置でもう一度」：記号・武器・方向・頭割り対象を再現。
- 「新しい配置で開始」：条件内で再抽選。
- お手本を見る：8人全員が自動。結果にお手本と表示。
- 復習ガイド：正解位置・ペア・距離を表示。通常はOFF。
- PT表示順は↑↓で変更、ローカル保存。マクロ優先度には影響しません。

## 時間・判定

| 秒 | 内容 |
|---:|---|
| 0–3 | 連携プログラムPT詠唱 |
| 5.5 | 頭上記号・ミドル／ファー付与 |
| 7.5 | 男女と目の出現 |
| 11.3 | 男女の範囲予兆 |
| 11.5 | 武器着弾・頭上記号消失 |
| 17.5 | 幅10mの目の直線＋半径5mのファイラ。同時に頭割りマーカー・男5人・女1人出現 |
| 25.5 | 中央の女から15m吹き飛ばし |
| 29 | 男5人の半径10m範囲＋半径6mの4人頭割り |

半径20mの円形MAP。床とマーカーは北固定。A1B2C3D4の時計回り配置。ペア間距離は常時判定し、ミドル15–20m、ファー35m以上が適正。条件外では被ダメージ増加、適正に戻れば解除。ファイラ・頭割りの着弾時に被ダメージ増加があれば即死。ファイラ同士の図形の重なりだけでは失敗にせず、他人の中心から5m未満で被弾します。

記号は5.5秒以上11.5秒未満のみ頭上表示。PT欄・デバフ欄には一切表示しません。距離デバフは付与後ずっと表示。復習ガイドは明示的な例外としてOFFを初期値にしています。

最初の武器攻撃：男剣は半径10m円、男盾は半径10m以内が安全、女杖は中央方向を軸に幅10mの十字、女足は中央方向へ幅10mの帯のみ安全。攻撃するのは外側の男と内側の女。装飾的な中央男・外側女は薄く表示します。キャラクター画像は直立表示、足元の矢印が中央への向きを示します。

## マクロ

左 H1 / MT / D1 / D3、右 H2 / ST / D2 / D4。下から調整。

- 同じ組で記号が重複した場合、その記号の下位者を左右で交換。
- ミドル：目を北に、左右とも○×△□。x=±8.5mの直線に並ぶ。
- ファー：左○×△□、右□△×○。半径19mに散開。
- 散開判定は距離と範囲に加え、担当側と記号の上下の帯も確認。点への完全一致は求めません。
- 頭割りが偏ったら下位の対象者と、その同記号ペアを交換。
- 後半は男3人側を北として左組は西、右組はミドルなら南／ファーなら東。方向は目と独立。

## 画像から推定した値・モデル上の仮定

ゲームの実測座標ではありません。設定は `engine.js` に集約しています。

- 通常速度6m/s、スプリント7.8m/sはシミュレーターの設定値。
- 最初の男 (8,-8)m、内側女 (-7,0)m、装飾の外側女 (-8,-13)m。全体を45度単位で回転。
- 後半の男は半径13.5m、北・北東・北西・南東・南西。中央女は原点。
- NPCの吹き飛ばし前半径は2m、着地は17m。その後ミドル頭割りは13.5m、ファーは18.5mへ調整。頭割り中の同組NPCは中心から±0.12mの微小分散。
- 頭割り2名は別記号から抽選。同記号の2名だと、確定した同記号交換ルールで偏りを解消できないためのモデル上の制約。
- 同じ優先段の左右ロールが調整後に同組となった場合の同順位は、固定ロール配列順で解決。
- 頭割りマーカーは17.5秒から29秒まで表示するモデル。
- 回復・ダメージ量・蘇生は再現せず、被弾／落下で戦闘不能。プレイヤー死亡で停止して理由を表示。
