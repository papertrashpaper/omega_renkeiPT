# 連携プログラムPT — OMEGA LAB

絶オメガ検証戦 P2「連携プログラムPT」の非公式ブラウザ練習シミュレーター。自分の1キャラクターを操作し、残り7人は自動移動します。外部サービス・APIキー・npm依存パッケージは不要です。

更新：開幕は西に男・東に女、両側でH1/MT/D1/D3とH2/ST/D2/D4が北から南へ待機。開幕男女は5.5秒に消え、7.5秒は4体を通常描画。ペア線は5.5秒以降表示。

## 起動

```sh
npm run dev
# http://localhost:5173
npm test
npm run build
```

GitHub Pagesはリポジトリの **Settings → Pages → Source: GitHub Actions** を選択してください。mainへのpushで `.github/workflows/pages.yml` が実行され、distを公開します。

想定URL: https://papertrashpaper.github.io/omega_renkeiPT/

## 操作

- WASD / 矢印：通常移動。斜め移動を正規化。
- クリック / タップ：移動先を指定。キーボード入力で解除。ドラッグはカメラ回転（5px以上でクリックと区別）。回転中も移動キーは画面方向に対応。
- Shift / スプリントボタン：10秒間のスプリント（リキャスト60秒）。
- Space：一時停止。別タブへの切替時も自動停止。
- 「同じ配置でもう一度」：記号・武器・方向・頭割り対象を再現。
- 「新しい配置で開始」：条件内で再抽選。
- 自動カメラ回転（初期ON）：11.5秒に目を画面上、19.0秒に男3人側を画面上へ。各0.5秒の実時間で最短方向に滑らかに回転。一時停止中は停止、ドラッグで中断。OFFでもドラッグ回転可能。北へ戻すボタンあり。
- お手本を見る：8人全員が自動。結果にお手本と表示。
- 復習ガイド：正解位置・ペア・距離を表示。通常はOFF。
- PT表示順は↑↓で変更、ローカル保存。マクロ優先度には影響しません。

## 時間・判定

| 秒 | 内容 |
|---:|---|
| 0–3 | 連携プログラムPT詠唱 |
| 5.5 | 頭上記号・ミドル／ファー付与 |
| 7.5 | 男女と目の出現 |
| 11.3 | 男女の範囲予兆 |
| 11.5 | 武器着弾・頭上記号消失 |
| 17.5 | 幅10mの目の直線＋半径5mのファイラ。同時に頭割りマーカー・男5人・女1人出現 |
| 25.5 | 中央の女から15m吹き飛ばし |
| 29 | 男5人の半径10m範囲＋半径6mの4人頭割り |

半径20mの円形MAP。ワールド座標ではAが北。カメラは任意に回転できます。A1B2C3D4の時計回り配置。ペア間距離は常時判定し、ミドル15–20m、ファー38m以上が適正。条件外では被ダメージ増加、適正に戻れば解除。ファイラ・頭割りの着弾時に被ダメージ増加があれば即死。ファイラ同士の図形の重なりだけでは失敗にせず、他人の中心から5m未満で被弾します。

記号は5.5秒以上11.5秒未満のみ頭上表示。PT欄・デバフ欄には一切表示しません。距離デバフは付与後ずっと表示。復習ガイドは明示的な例外としてOFFを初期値にしています。

最初の武器攻撃：男剣は半径10m円、男盾は半径10m以内が安全、女杖は中央方向の幅10m帯と、それに直交する幅24m帯の十字、女足は中央方向へ幅10mの帯のみ安全。攻撃するのは外側の男と内側の女。中央男・外側女も同じ大きさ・不透明度で表示します。キャラクター画像は直立表示、方向を示す補助線は表示しません。

## マクロ

左 H1 / MT / D1 / D3、右 H2 / ST / D2 / D4。下から調整。

- 同じ組で記号が重複した場合、その記号の下位者を左右で交換。
- ミドル：目を北に、左右とも○×△□。x=±8.5mの直線、y=-17.5,-5.5,5.5,17.5mに並ぶ。
- ファー：左○×△□、右□△×○。半径19.5m、y=-18.3,-5.5,5.5,18.3mに散開。北南端を外周に寄せ、中間のスペースを確保。
- 散開判定は距離と範囲に加え、担当側と記号の上下の帯も確認。点への完全一致は求めません。
- 頭割りが偏ったら下位の対象者と、その同記号ペアを交換。
- 後半は男3人側を北として左組は西、右組はミドルなら南／ファーなら東。方向は目と独立。

## 画像から推定した値・モデル上の仮定

ゲームの実測座標ではありません。設定は `engine.js` に集約しています。

- 通常速度6.25m/s、スプリント8.125m/sはシミュレーターの設定値。
- 最初の男 (8,-4)m、内側女 (-8,4)m、外側女 (-8,-8)m、中央男 (0,0)m。全体を45度単位で回転。
- 後半の男は半径13.5m、北・北東・北西・南東・南西。中央女は原点。
- NPCの吹き飛ばし前半径は2m、着地は17m。その後ミドル頭割りは13.5m、ファーは19.4mへ調整。頭割り中の同組NPCは中心から±0.12mの微小分散。
- 頭割り2名は別記号から抽選。同記号の2名だと、確定した同記号交換ルールで偏りを解消できないためのモデル上の制約。
- 同じ優先段の左右ロールが調整後に同組となった場合の同順位は、固定ロール配列順で解決。
- 頭割りマーカーは17.5秒から29秒まで表示するモデル。
- 回復・ダメージ量・蘇生は再現せず、被弾／落下で戦闘不能。プレイヤー死亡で停止して理由を表示。

## ファイル

- `engine.js`：メートル座標、タイムライン、NPC、判定
- `app.js`：Canvas描画・操作・画面表示
- `assets/`：指定のデバフアイコン画像と今回生成した4種類のキャラクター画像（WebP最適化）。MAP・マーカー・プレイヤーはベクター描画

## 避け方・演出の調整

NPCと復習ガイドは盾＋杖／剣＋杖／盾＋足では男周辺、剣＋足では女周辺の安置を優先。剣の半径10m範囲は必ず避けます。女杖は女側外周の安置を消すため、十字の横腕を幅24mに拡張（中央を向く帯は幅10m）。予兆と被弾判定は同じ計算です。

目着弾後の自動回転は17.5秒から1.5秒待機して19.0秒に開始、0.5秒で回転。最初の11.5秒の回転は変更なし。

吹き飛ばし予兆は23.5～25.5秒。中央の波紋・外向き矢印・残り秒数を表示。25.5～27.0秒の1.5秒間、15mの強制移動を行い、その間通常移動は停止します。27秒で操作を再開し、29秒に頭割り判定。停止・スロー再生は吹き飛ばしにも適用。
